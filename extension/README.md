# 🛡️ ScamShield Browser Extension (Manifest V3)

Proactively inspects incoming webmail (Gmail, Outlook) and web messaging (WhatsApp Web) links in real-time.

## 🚀 How to Install in Chrome / Edge / Brave

1. Open your browser and navigate to:
   * **Chrome**: `chrome://extensions`
   * **Edge**: `edge://extensions`
   * **Brave**: `brave://extensions`
2. Enable **Developer mode** (toggle in the top-right corner).
3. Click the **Load unpacked** button.
4. Select this `extension` directory (`ScamShield/extension`).
5. The **ScamShield** shield icon will appear in your browser extensions bar!

## 🌟 Key Capabilities
* **In-Page Real-time Flagging**: Highlights suspicious unverified links and deceptive TLDs with safety tags.
* **Popup Quick Scanner**: Instantly check any URL before clicking.
* **Context Menu**: Right-click any highlighted message text to inspect it with ScamShield.
